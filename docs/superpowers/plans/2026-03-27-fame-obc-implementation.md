# FAME OBC/Prometheus Integration Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ObsByClara/Prometheus Remote Write as a third metrics backend to the `monitoring-function` module, maintaining backward compatibility with Splunk and Datadog.

**Architecture:** Add 7 new OBC variables to the inner module (`modules/monitoring-function/`) and mirror them at the root level with a `monitoring_function_` prefix. Update `app_settings` in locals with null guards. Add a cross-validation precondition alongside the updated "exactly 1 backend" precondition. No resource renames, no `moved` blocks.

**Tech Stack:** OpenTofu/Terraform HCL. Validation via `pre-commit` hooks (`tofu_fmt`, `tofu_validate`, `tofu_docs`, `tofu_tflint`).

## Task 2: Update app_settings in inner module locals

**Files:**
- Modify: `modules/monitoring-function/locals.tf` (lines 16-25, the `app_settings` merge)

- [ ] **Step 1: Replace the `app_settings` merge block** with the extended version

Current block (lines 16-25):
```hcl
  app_settings = merge(
    {
      LOG_ANALYTICS_WORKSPACE_GUID = var.log_analytics_workspace_guid,
      SUBSCRIPTION_ID              = data.azurerm_client_config.current.subscription_id,
      METRICS_EXTRA_DIMENSIONS     = local.extra_dimensions,
    },
    var.extra_application_settings,
    var.splunk_token != null ? { SFX_TOKEN = var.splunk_token } : {},
    var.datadog_api_key != null ? { DD_API_KEY = var.datadog_api_key } : {},
  )
```

Replace with:
```hcl
  app_settings = merge(
    {
      LOG_ANALYTICS_WORKSPACE_GUID = var.log_analytics_workspace_guid,
      SUBSCRIPTION_ID              = data.azurerm_client_config.current.subscription_id,
      METRICS_EXTRA_DIMENSIONS     = local.extra_dimensions,
    },
    var.extra_application_settings,
    var.splunk_token != null ? { SFX_TOKEN = var.splunk_token } : {},
    var.datadog_api_key != null ? { DD_API_KEY = var.datadog_api_key } : {},
    var.obc_endpoint != null ? { OBC_ENDPOINT = var.obc_endpoint } : {},
    var.obc_region != null ? { OBC_REGION = var.obc_region } : {},
    var.obc_endpoint != null ? { OBC_SERVICE = var.obc_service } : {},
    var.obc_aws_access_key_id != null ? { AWS_ACCESS_KEY_ID = var.obc_aws_access_key_id } : {},
    var.obc_aws_secret_access_key != null ? { AWS_SECRET_ACCESS_KEY = var.obc_aws_secret_access_key } : {},
    var.obc_aws_session_token != null ? { AWS_SESSION_TOKEN = var.obc_aws_session_token } : {},
    var.obc_max_retries != null ? { OBC_MAX_RETRIES = tostring(var.obc_max_retries) } : {},
  )
```

> **Note:** `OBC_SERVICE` is gated on `obc_endpoint != null` (not `obc_service != null`) because `obc_service` has a non-null default `"aps"` and would otherwise always be injected. For the same reason, `obc_service` must NOT appear in the `compact()` list in any precondition.
